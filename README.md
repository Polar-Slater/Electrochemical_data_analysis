# Electrochemical data analysis toolbox

Note: The code in this toolbox was generated with assistance from AI.

This GUI opens the existing electrochemical plotting tools from one control panel:

- Open circuit voltage
- Durability
- Experiment procedure
- Reference electrode potential
- ECSA identifier
- LSV Plotter
- EIS Plotter
- Folder batch plotter

Run `Start Electrochemical Toolbox.bat`, then click one of the four large buttons to switch to that function inside the same window. Use the Return button on each tool page to go back to the initial page.
